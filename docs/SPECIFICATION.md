# Reverb Time Remapping — 残響時間分離・再構成システム 実験仕様書

状態: 正規版の上位実験仕様。R1の詳細な時間・処理契約は [TIME_MODEL_CONTRACT.md](TIME_MODEL_CONTRACT.md) を参照。音響的有効性・本番DSP・正規版公開は未検証。

## 1. 目的
残響の反射・拡散・減衰・周波数構成・位相関係の時間発展を独立制御し、任意時点の状態を参照・持続・伸縮・逆行・反復できるようにする。通常のリバーブを包含する一般化された処理系を、実際の音声出力で検証する。各方式を同一条件で比較試聴できるWebプロトタイプとする。

## 2. 基本原理
x(s) は入力信号、h(τ) はIR、s は入力時刻、τ は残響経過時間、t は出力時刻。
通常の畳み込みでは t=s+τ、R(s,τ)=x(s)h(τ)、y(t)=Σ_s R(s,t−s)。
入力とIRを分離して保持し、参照時刻と合成時刻の対応を変更できること。通常の畳み込みは時間関係を変更しない特殊例。
入力はミックス済みの単一信号とし、個別楽器・音源の識別・分離は行わない。ステレオ等のチャンネル関係は保持する。

## 3. IRの時間周波数分解
IRをSTFT等で分解し、時間位置・周波数・振幅・位相・チャンネル間関係を保持。任意の局所時間窓の波形を持続的に再合成し、参照位置を固定しても波形の振動は継続する。単純な振幅スペクトル固定だけでなく、元の局所波形・位相・干渉特性を可能な限り保持する。局所状態の定常化は近似であり、物理的音場の完全停止を意味しない。

## 4. 独立制御する時間軸
- Source Time：原音の参照時刻。
- IR Time：IR内の残響経過時間。
- Wet Time：合成された残響音の参照時刻。
- Output Time：実際に出力する時刻。
- Waveform Phase：波形の振動・位相進行（物理的時間軸ではなく独立再合成の概念）。
各参照軸を連動・独立操作可能とする。IRの局所特性の固定と発生済みWetの固定を区別する。出力クロック自体は通常進行し、参照座標を変更する。

## 5. 時間操作
原音・IR・Wetの位置について任意移動、等速、低速、高速、固定、逆方向、区間反復・往復。シークバーで試聴中にも操作可能。原音とWetの連動・独立を選択。IR操作は波形再生速度を変える方式と、振動速度を維持して状態だけを移動する方式を区別する。

## 6. 時間操作による音響効果
| 操作 | 効果 |
|---|---|
| 全軸を通常進行 | 通常のリバーブ |
| IR進行を低速・高速化 | 残響状態の伸長・圧縮 |
| IR参照位置固定 | 特定の反響特性の持続 |
| IR逆行・往復 | 残響特性の逆方向変化・反復 |
| 原音とWetを同一時間座標で反転 | 全体の逆再生 |
| 原音を維持してIRの時間関係を反転 | 原音に向かう逆方向の残響（位置補正） |
| 発生済み残響参照状態固定 | 残響全体の持続 |
通常進行・全体の逆再生は元波形と数値的に一致。固定・伸縮・振動速度維持の逆行は再合成を伴うため近似精度を検証する。単一の局所IR断面を再合成して新規入力へ適用するだけでは発生済みWetの固定・巻き戻しと同じにならない。

## 7. 発生済み残響の操作
入力停止後にも残響状態の固定、減衰した残響の巻き戻し、初期反射への回帰、区間反復、再進行を可能とする。入力信号とIRの時間的対応を保持して必要に応じ再計算・再合成。入力サンプルごとの寄与行列の全展開・保存は必須でなく、等価な効率的処理を許容する。

## 8. Predelayの一般化
符号付きPredelayで原音と残響の配置を変更（正＝後方、0＝移動なし、負＝前方）。残響進行方向とは独立。逆転IRの終端を原音に合わせる場合はIR長に応じて時間位置補正を行う。

## 9. キャッシュ
入力の過去区間・事前取得区間、IR原波形・時間周波数分解、再構成に必要な状態、必要に応じWet信号を保持可能。未来入力が必要な場合は事前読み込みまたはLookaheadによる遅延を許容。キャッシュは逆再生専用でなく任意参照の共通機構。保持範囲外・未準備状態を明示し、無限履歴を仮定しない。

## 10. 調整パラメータ
Source Position/Speed、IR Position/Speed、Wet Position/Speed、Phase Mode、Window Size、Signed Predelay、IR Range、Wet/Dry、Gain。共通のリバーブ時間・IR選択も調整可能。参照位置は秒と相対位置を表示。速度の符号で方向、0で参照固定。ループ・往復範囲も操作できること。

## 11. 比較試聴モード
| モード | 処理内容 |
|---|---|
| Dry | 原音 |
| Normal Convolution | 通常の畳み込み |
| Reverse Convolution | 時間位置補正済み逆転IRによる畳み込み |
| Wet Buffer Scrub | Wet波形の直接操作（固定時は局所ループ） |
| Wet Spectral Scrub | Wet信号の時間周波数再合成 |
| IR Window Scrub | IRの部分抽出・畳み込み |
| IR Spectral Remapping | IRの時間周波数分解・時間操作・再合成 |
| Integrated Remapping | 原音・IR・Wetの時間関係を独立制御する統合方式 |
主要検証対象は最後の2方式。各方式は同一音源・同一IRを用い、共通設定・参照位置・速度・方向を可能な限り維持。A/B切替、Dry/Wet個別試聴、自然減衰と音量補正の切替。キャッシュ方式と現在入力追従方式を明示する。

## 12. 試験音源・IR
標準音源：インパルス、サイン波、矩形波・鋸歯状波、ホワイトノイズ、持続和音、ピアノ単音・フレーズ、ドラム。発振音は周波数変更・持続・停止可能。
標準IR：単発Delay、等間隔・不規則な多重反射、初期反射主体、高密度な後期残響、周波数別減衰の異なるIR。任意音声・IRファイルを読み込めること。標準素材は自作・生成等の適法なものとする。

## 13. 可視化
原音波形、IR原波形、IRスペクトログラム、再合成IR波形、Wet波形、Wetスペクトログラム、現在の出力スペクトル、IR周波数応答、各参照位置・抽出窓を実処理データから表示。波形・スペクトログラムで位置を直接操作可能。疑似波形で実処理を装わない。

## 14. 検証項目
基本処理：通常の時間関係が通常畳み込みと一致、インパルス入力のWetがIRに一致、原音とWetの共通座標反転が通常出力の逆再生と一致（長さ・基準位置を揃える）、単純Delayの位相干渉・コムフィルター特性を再現。
独立性：IR位置固定中も振動が継続、残響進行速度と音程変化を分離、拡散・減衰・周波数構成の逆方向変化、入力停止後の参照操作。
聴感評価：元の反響特性保持、固定の自然さ、逆行の収縮感、人工周期性、位相干渉、クリック・音割れ、従来Wet操作との差、持続音・瞬間音・入力変化への挙動。聴感未評価を数値試験で代替しない。

## 15. 完成条件
- 全8モードで実際に処理・再生でき、方式の違いを聴き比べられる。
- 原音・IR・Wet位置を連動/独立操作でき、固定・逆行・伸縮・往復が反映される。
- 通常畳み込み・完全逆再生との数値一致を明示した許容誤差内で確認。
- 入力停止後の残響操作が可能。
- 可視化が実際の処理と一致。
- 近似・非対応・キャッシュ範囲等の制約を明示。
- 異常な音量上昇、クリック、音割れを抑え安全に試聴できる。無限IRの連続励振による蓄積に対する出力制御を備える。
- PC・スマートフォンのブラウザで実操作できる。

## 16. 開発範囲
音響原理の検証用Webプロトタイプ。事前計算・キャッシュ・非リアルタイム処理を許容、製品水準の低遅延性は不要。ただし試聴中に参照位置を操作して効果を確認できること。具体的ライブラリ・言語・データ構造・再合成アルゴリズムは未指定。個別音源の分離、物理空間全体の波動シミュレーション、VST化、クラウド保存、アカウント管理は対象外。既存共通機構の再利用を実装前に確認し、全repoへの適用は完成条件としない。先行Muse版は prototype/ に保持し、正規版の工程・受入状態は Issue #4 を参照。
